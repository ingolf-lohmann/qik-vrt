# Publication package

This directory preserves two distinct scholarly objects:

1. `ORIGINAL_ARTICLE.md` - the authored article by Ingolf Lohmann.
2. `META_REVIEW.md` - a separate scientific and verification-oriented meta-review.

`PUBLICATION.json` records authorship, licensing, repository targets, Zenodo intent and the fail-closed verification status.

The original article is not silently rewritten by the meta-review. A Zenodo DOI may be recorded only after the live workflow returns a published record and the uploaded bytes are verified against their local SHA-256 digests.
