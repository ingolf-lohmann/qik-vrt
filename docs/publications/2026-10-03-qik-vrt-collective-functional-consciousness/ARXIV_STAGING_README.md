## Proposed title

**From Artificial Cognition to Evidence-Bound Functional Self-Continuity: QIK-VRT Memory, Effect Readback, and Heterogeneous Collective Cognition**

## Proposed abstract

We describe a systems architecture that combines generative artificial cognition with persistent provenance-bound memory, effect readback, epistemic claim status, and recursive revision. The central engineering invariant separates representation, execution, external effect, observation, and accepted evidence. We define a functional self-continuity criterion under which past machine states remain attributable, temporally bounded, and revisable rather than being silently transferred to successor states. We further describe a heterogeneous collective-cognition model in which independently identified repository instances preserve disagreement and reciprocal provenance rather than collapsing observations into an unaudited consensus. A deterministic microbenchmark shows that provenance-bound delta reconciliation can reduce comparison work relative to complete rescanning when state drift is sparse; this microbenchmark is not a live distributed Authority/Mirror speedup measurement. We define falsification criteria for persistence, temporal identity, self-reference, recurrence, metacognition, effect binding, revision, and restart continuity. The term functional artificial consciousness is used only for the explicitly defined operational property set; phenomenal consciousness is not claimed.
