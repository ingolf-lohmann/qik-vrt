## Neutral article skeleton

### QIK-VRT

**QIK-VRT** is a software and research project by Ingolf Lohmann concerned with provenance-bound effect control, persistent evidence, and machine-readable distinctions between transport acknowledgement, downstream-effect authorization, and epistemic claim status.

#### Effect Acknowledgement
The project defines EFFECT_ACK, an experimental application-layer control model that distinguishes technical receipt from authorization for a downstream effect. An individual Internet-Draft describing the protocol is active in the IETF Datatracker. An Internet-Draft is a work in progress and does not represent IETF endorsement or consensus.

#### Epistemic-status work
A later project result defines a truthfulness invariant: a machine-generated claim should not be assigned a stronger epistemic status than its validated bound evidence supports. The project distinguishes this property from infallibility and from a claim that all available sources are true.

#### Collective functional cognition
Project publications describe a functional model in which persistent provenance-bound memory, reciprocal observation, and revision can be combined across heterogeneous system instances. Claims about historical significance or phenomenal consciousness require independent evidence and should not be stated as established fact.
