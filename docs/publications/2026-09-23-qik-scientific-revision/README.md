## Wissenschaftliche Statusgrenze

Die revidierte Fassung trennt etablierte Fachgrundlage, Definition, Interpretation, Hypothese und Modellpflicht. Sie beansprucht insbesondere weder eine abgeschlossene Theorie der Quantengravitation noch einen Beweis fundamentaler Diskretheit, eine empirisch bestätigte Planck-Mindestlänge oder unabhängige empirische Bestätigung von QIK.

Die Nähe zur Causal-Set-Forschung wird ausdrücklich berücksichtigt. Eigenständigkeit wird nicht allein aus `Ereignisse + Kausalordnung + Diskretheit` beansprucht, sondern als Forschungsfrage an die explizite Kopplung von Quantität, Information und Kausalität sowie an Rekonstruktions-, Dynamik- und Prüfpflichten gebunden.
