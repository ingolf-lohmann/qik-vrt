## Gegenstand

Dieses Bündel konsolidiert die technische, mathematische, physikalische,
allgemeinverständliche und erkenntnistheoretische Beschreibung eines
selbstheilenden, anschlussfähigen Repositorys.

Es verbindet fünf Schichten:

1. deterministische technische Selbstheilung;
2. Erhalt von Evidenz und historischen Zuständen;
3. strukturgebundene Wiederverwendung guter Ideen;
4. kollektive, geteilte Intelligenz durch nachvollziehbar verbundene Beiträge;
5. epistemische Rückwirkung ohne Behauptung physikalischer Vergangenheitsmutation.
