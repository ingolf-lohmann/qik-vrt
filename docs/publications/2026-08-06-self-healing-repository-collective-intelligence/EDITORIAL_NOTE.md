# Redaktioneller Konsolidierungsvermerk

Diese Fassung ist der erste eingefrorene Repository-Publikationskandidat des
vorliegenden Gesamtartikels.

Sie konsolidiert zuvor im Gespräch entstandene Textblöcke. Dabei wurden:

- doppelte Abschnitte zusammengeführt;
- wiederholte Beispiele gekürzt oder systematisch eingeordnet;
- die mathematische Notation vereinheitlicht;
- „begrifflich-architektonische Vollkugel“ von formaler, empirischer und
  physikalischer Vollständigkeit getrennt;
- Retrokausalität ausdrücklich als epistemische Rückwirkung ohne
  Vergangenheitsmutation begrenzt;
- Ideenerhalt, Domänenadapter und kollektive Intelligenz in eine gemeinsame
  Dramaturgie integriert.

Es existierte vor diesem Kandidaten keine eingefrorene repositoryseitige
Primärfassung desselben Gesamtartikels. Deshalb ist dies eine
Erstmaterialisierung und keine stille Korrektur eines früheren
Repository-Kandidaten.
