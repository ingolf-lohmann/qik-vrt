feat(eap): Mirror client for the existing public EAP route

Non-browser client for a Mirror principal on the existing S1 public
EAP routes (runtime/self-host/EAP_HTTP.md): discovery, state, prepare,
record and context readback, local revision-03 release verification,
commit and receipt readback. Adds no listener, route, executor or
credential store; the bearer comes only from an environment variable.
Accepted text stays an observation, never a command.

Tests run against the original Runtime, OwnerREST and EAP handler over
real local HTTP with the same isolated principal fixture as
tests/test_effect_ack_http_service.py: delivery with idempotent replay,
wrong token/principal, tampered context, plain-HTTP remote refusal.
Wired into make conformance. Local acceptance only, not VPS delivery.
