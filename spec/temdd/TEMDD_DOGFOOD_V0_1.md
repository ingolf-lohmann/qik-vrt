# TEMDD dogfood program

`examples/temdd/qikvrt_convergence_v0_1.temdd` is the first production-shaped TEMDD program. It intentionally targets the complete QIK-VRT DoD and therefore cannot compile if that canonical conjunction is weakened. The program follows exact evidence on events and derives a smallest sound successor on blockers. Execution of repository effects remains delegated to admitted QIK-VRT actors; the bootstrap parser itself has no ambient mutation authority.
